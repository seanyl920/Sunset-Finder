# 🌇 Sundown — Sunset Forecast & Discovery

A premium, atmospheric web app that tells you how good tonight's sunset will be,
lets you plan the week ahead, and uses **Claude** to recommend the best local
spots to watch it from.

![spots curated by Claude](https://img.shields.io/badge/spots-curated%20by%20Claude-e84d97)

## What it does

- **Search any city or use your location** to read the sky.
- **Sunset Quality Score (1–10)** computed from live cloud cover (high / mid /
  low), humidity, and visibility — high cirrus catches color, low cloud blocks
  the sun, dry clear air keeps hues vivid.
- **Plain-language verdict**, e.g. _"High cirrus clouds + low humidity for vivid
  color."_
- **7-day forecast** with a score bar for every evening, so you can plan ahead.
- **Curated watching spots** generated by the Claude API — each with a name, a
  one-line reason it's great for sunsets, and the best time to arrive.

## Architecture

It's a real, working app — not a mockup.

| Data | Source | Key needed? |
| --- | --- | --- |
| City → coordinates | [Open-Meteo Geocoding](https://open-meteo.com/) | No |
| Sunset time (today) | [Sunrise-Sunset API](https://sunrise-sunset.org/api) | No |
| Clouds / humidity / visibility & 7-day sunsets | [Open-Meteo Forecast](https://open-meteo.com/) | No |
| Curated spots | **Claude API** (`claude-opus-4-8`) | **Yes** |

The weather/sunset APIs are free, CORS-enabled, and called directly from the
browser. The Claude call goes through a small **Express server** (`server/`) so
your `ANTHROPIC_API_KEY` stays server-side and is never shipped to the client.

```
browser (React)  ──►  Open-Meteo / Sunrise-Sunset   (direct, no key)
        │
        └──► /api/spots ──► Express ──► Claude API   (key stays here)
```

## Getting started

```bash
# 1. Install
npm install

# 2. Add your Claude key
cp .env.example .env
#   then edit .env and set ANTHROPIC_API_KEY=sk-ant-...

# 3. Run (starts Vite on :5173 and the API server on :3001)
npm run dev
```

Open http://localhost:5173.

> Without an API key the forecast and scores work fully — only the
> Claude-curated spots are disabled, with a friendly message.

### Production build

```bash
npm run build   # bundles the React app into dist/
npm start       # Express serves dist/ AND /api on http://localhost:3001
```
